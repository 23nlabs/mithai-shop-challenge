# Operations and troubleshooting

This is a static research and command-line verification package. It has no server, persistent service, container image, health endpoint, Render configuration or hosted deployment. Version identification is the public Git commit and `PACKAGE.sha256`; scientific source is `7069f5a78898076b07014a3d913a1424fc02e53f`.

Run `python3 verify_release.py` and `python3 audit_public.py` from the package root. For claim recomputation, make a disposable copy and run `python3 robustness/v3/src/claims_check.py`; it writes `final/claims-ledger.json`. The two read-only gates emit JSON lines to stdout with UTC time, severity, event, app/version, per-run correlation ID, outcome, duration in milliseconds, counts and stable error codes. Capture output in a private bounded log when diagnosing; logs do not persist automatically. Counts reset each invocation and success/failure are represented by completion events. Rotate or delete captured logs after review, and redact local paths and credentials before sharing.

The three notebooks are unexecuted templates. Their source execution used staged JSONL logs retained privately; those runtime logs and any account metadata are not published. The raw synthetic `.npz` archives are omitted, so `final_verify.py` cannot recount all forecasts from this repository alone. Regenerate the archives as described in `REPRODUCIBILITY.md` before attempting that check. Do not launch GPU jobs just to resolve a document or metadata error.

A `HASH_MISMATCH` means a committed file changed: compare it with `PACKAGE.sha256`. `NOTEBOOK_SCOPE` or `NOTEBOOK_OUTPUT` indicates publication hygiene failed. `PRIVACY_MATCH`, `UNEXPECTED_FILE`, `LICENSE_MISSING`, `CALENDAR_PROVENANCE`, or `DATA_INVENTORY` from `audit_public.py` blocks publication and names the file or field without dumping sensitive content. `HISTORY_HASH_MISMATCH` means regenerated synthetic inputs differ: compare Python/NumPy versions and `data/festivals.json`. `WEIGHT_HASH_MISMATCH` or `REVISION_MISMATCH` means a publisher artifact differs; stop. `SHAPE`, `NONFINITE`, or `CROSSED_QUANTILES` means a forecast contract failure. For a claims failure, use the claim ID to inspect the named result JSON and text. External model downloads can fail or time out; record publisher, model revision, status and retry outcome, without logging credentials or full payloads.

For an issue or fix PR, include symptom, UTC time, public commit and source commit, run ID, sanitized error code/evidence, reproduction command, expected and actual behavior, and checks run. Never attach credentials, account identifiers, private paths, raw non-synthetic data or unrelated sealed forecasts.
